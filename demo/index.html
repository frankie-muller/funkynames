funkynames

Three-word names from six curated pools — and, unusually, the arithmetic that says what they're worth. A three-word name feels about as unguessable as a password. It isn't, and the gap is where the bugs live. Source on GitHub.

Handles

Three structured slots — descriptor, colour or action, place or thing. Reads like a name. No word repeats.

    Flat draws from every pool at once. Any word, any position — worth more bits per word, reads less like a name.
